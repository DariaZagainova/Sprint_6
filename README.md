# Sprint_6 / Page Object /  Учебный сервис «Яндекс.Самокат» — Автоматизированные тесты

## О проекте

Данный набор тестов автоматизирует проверку ключевых сценариев веб-приложения [Учебный сервис «Яндекс.Самокат»](https://qa-scooter.praktikum-services.ru/).   
Тесты написаны с использованием Pytest, Selenium WebDriver и Allure.

### Проверяемые сценарии

1. **Выпадающий список в разделе «Вопросы о важном»**
   - Проверяется, что при клике на вопрос открывается корректный текст ответа.

2. **Флоу заказа самоката (позитивный сценарий)**
   - **Точки входа:** кнопка «Заказать» в шапке страницы и кнопка «Заказать» в середине страницы.
   - **Действия теста:**
     1. Нажатие кнопки «Заказать».
     2. Заполнение формы заказа с использованием двух различных наборов данных.
     3. Проверка появления всплывающего окна с сообщением «Заказ оформлен».
     4. Проверка перехода на главную страницу по клику на логотип «Самокат».
     5. Проверка открытия главной страницы Яндекс Дзена в новой вкладке через редирект по клику на логотип «Яндекс».


## Структура проекта

**conftest.py** — фикстуры Pytest для инициализации драйвера и открытия главной страницы, открытия страницы заказа.   
**curl.py** — URL'ы.  
**data.py** — тестовые данные.  
**helpers.py** - вспомогательные функции для упрощения и повторного использования логики в автотестах.   
**requirements.txt** - список зависимостей проекта, необходимых для запуска тестов.   

**locators/** — папка, содержащая локаторы элементов страниц:  
    - header_components_locators.py - локаторы шапки страниц.  
    - main_page_locators.py - локаторы главной страниицы.  
    - order_page.py - локаторы страницы заказа.  

**pages/** — директория с классами страниц, и с методы взаимодействия с элементами веб-приложения (паттерн Page Object):
    - base_page.py — базовый класс с общими методами для всех страниц:  
    - header_component.py — для работы с элементами шапки сайта.  
    - main_page.py — для взаимодействия с элементами главной страницы.  
    - order_page.py — для работы со страницей оформления заказа.  

**tests/** — папка с тестами по функциональным блокам:  
    - test_faq_accordion.py — тесты для раздела «Вопросы о важном», проверка раскрытия вопросов и соответствия ответов вопросам.  
    - test_logo_navigation.py — тесты проверки переходов по логотипам в шапке страницы оформления заказа («Самокат», «Яндекс»).  
    - test_order_flow.py — тесты позитивного сценария оформления заказа самоката с разными наборами данных и точками входа («Заказать» сверху и в середине страницы).

**allure-results/** — папка с результатами прогонов тестов для генерации Allure-отчёта.  


## Инструкция по запуску:

#### Установите зависимости:

> pip install -r requirements.txt</h>

#### Запустить все тесты и записать отчет:

> pytest --alluredir=./allure-results

### Посмотреть отчет по прогону, html

> allure serve ./allure-results
